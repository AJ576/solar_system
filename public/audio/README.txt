Custom Audio Directory for Galactic Cruise
===========================================

This directory is optional. The game includes a 100% procedural Web Audio synthesizer
that generates dynamic flight engines, atmospheric wind, kinetic impact collisions,
footsteps, cockpit UI blips, hyperspace transitions, and lush evolving ambient space music!

If you want to use your own custom soundtrack:
1. Place your audio file here and name it:
   - `music.mp3` or `music.ogg`
2. The game will automatically detect it and play your track seamlessly in the background!
3. If no file is placed here, the game uses its built-in procedural ambient cosmic synthesizer.
